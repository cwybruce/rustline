Rustline is an original top-down 2D open-world crime game set in a desert highway town at dusk: drive the Route 9 highway, steal cars, outrun highway patrol, and run four jobs for Old Pete at the gas station. Vanilla canvas, no libraries, no network calls.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in your browser.

## How to play

- WASD / arrow keys — move and drive
- E — enter / exit a car
- Mouse aim + click — shoot the pistol
- F — punch, R — reload
- P — pause, G — save, L — continue, M — mute
